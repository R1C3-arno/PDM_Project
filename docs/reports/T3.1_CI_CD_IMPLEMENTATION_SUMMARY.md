## Pipeline Architecture

### Build Flow

```
Push/PR → Change Detection → Component CI → Security Scan → Quality Checks → Merge Gate
```

### Frontend CI Flow

```
Checkout → Setup Node.js → Cache Deps → Install → Lint → Type Check → Build → Upload Artifacts
```

### Backend CI Flow

```
Checkout → Setup JDK → Cache Maven → Compile → Test → Coverage → Package → Upload Artifacts
```

### Security Scan Flow

```
Checkout → Frontend Audit → Backend Check → CodeQL → Gitleaks → Semgrep → Summary
```

### PR Check Flow

```
Detect Changes → Run Component CI (conditional) → Security Scan → Validate PR → Code Quality → All Pass Gate
```

## Key Features

### 1. Intelligent Build Optimization
- **Dependency Caching:** Reduces build time by caching npm and Maven dependencies
- **Conditional Execution:** Only runs component CI if that component changed
- **Parallel Execution:** Runs independent jobs in parallel
- **Concurrency Control:** Cancels outdated workflow runs

### 2. Comprehensive Security
- **Multi-Layer Scanning:** npm audit, OWASP, CodeQL, Gitleaks, Semgrep
- **Automated Detection:** Runs on every PR and weekly schedule
- **Secret Protection:** Prevents committed secrets
- **Vulnerability Tracking:** 30-day retention for security reports

### 3. Quality Gates
- **Code Quality:** ESLint, type checking, console.log detection
- **PR Standards:** Title format, description requirements, branch naming
- **Merge Protection:** All checks must pass before merge
- **Conflict Detection:** Prevents merging with conflicts

### 4. Developer Experience
- **Clear Templates:** Standardized PR and issue templates
- **Comprehensive Checklists:** Ensures nothing is missed
- **Build Summaries:** Clear status reporting
- **Fast Feedback:** Cached builds provide quick feedback

### 5. Automated Maintenance
- **Dependabot:** Daily dependency updates
- **Grouped Updates:** Minor/patch updates grouped
- **Auto-Labeling:** Automatic PR categorization
- **Security Priority:** Security updates prioritized

## Usage Guide

### For Developers

#### Creating a Pull Request
1. Create feature branch: `feature/your-feature-name`
2. Make changes and commit with conventional format
3. Push to GitHub
4. Create PR using template
5. Wait for CI checks to pass
6. Address any feedback
7. Merge when approved

#### Running CI Locally

**Frontend:**
```bash
cd pdm-frontend
npm ci
npm run lint
npx tsc --noEmit
npm run build
```

**Backend:**
```bash
cd pdm-backend
mvn clean compile
mvn test
mvn package
```

#### Viewing Build Status
- Check Actions tab in GitHub
- Click on workflow run
- Expand job to see details
- Download artifacts if needed

### For Maintainers

#### Reviewing Dependabot PRs
1. Check changelog for breaking changes
2. Review automated test results
3. Merge if tests pass and no breaking changes
4. Group related updates when possible

#### Handling Security Alerts
1. Review security scan results weekly
2. Prioritize critical vulnerabilities
3. Create issues for tracking
4. Apply patches promptly

#### Updating Workflows
1. Make changes in feature branch
2. Test with sample PRs
3. Create PR for review
4. Merge to main after approval

## Troubleshooting

### Common Issues

#### Build Fails with Cache Issues
**Solution:** Delete cache from Actions UI or clear locally

#### Workflow Doesn't Trigger
**Solution:** Check branch name and path filters in workflow YAML

#### Permission Errors
**Solution:** Verify GitHub token permissions in workflow

#### Security Scan False Positives
**Solution:** Add exceptions to scan configuration or use ignore files
