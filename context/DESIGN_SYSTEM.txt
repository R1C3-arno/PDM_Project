4. STATE TRANSITIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Application Workflow:
  DRAFT → SUBMITTED
  SUBMITTED → UNDER_REVIEW
  UNDER_REVIEW → VERIFICATION_IN_PROGRESS
  VERIFICATION_IN_PROGRESS → VERIFIED / REJECTED
  VERIFIED → RISK_ASSESSMENT_IN_PROGRESS
  RISK_ASSESSMENT_IN_PROGRESS → RISK_ASSESSED
  RISK_ASSESSED → OFFER_GENERATED
  OFFER_GENERATED → OFFER_SENT
  OFFER_SENT → OFFER_ACCEPTED / OFFER_REJECTED
  OFFER_ACCEPTED → CONTRACT_CREATED
  CONTRACT_CREATED → CONTRACT_SIGNED
  CONTRACT_SIGNED → DISBURSED
  DISBURSED → ACTIVE
  ACTIVE → COMPLETED / OVERDUE

UI Rules:
  → Disable actions that violate state machine
  → Show tooltip explaining why action disabled
  → Highlight current state in timeline
